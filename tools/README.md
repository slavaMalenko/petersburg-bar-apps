# Tools

Эта директория содержит конфигурационные пакеты и инструменты, используемые в проекте Petersburg Bar.

## Структура

Каждый пакет в этой директории должен:
- Иметь префикс `@petersburg-bar/` в имени пакета
- Содержать свой собственный package.json
- Быть опубликован как отдельный npm-пакет (если требуется)

## Назначение

Здесь размещаются:
- Конфигурационные файлы (например, для TypeScript, ESLint, Jest и т.д.)
- Общие инструменты сборки
- Утилиты для разработки
- Другие технические пакеты, не относящиеся к бизнес-логике
